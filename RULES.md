# AURA Project Rules
- Docs are source of truth; inspect actual repo first.
- Separate dev/staging/prod; never commit secrets.
- Enforce server-side auth, least privilege, MFA, private evidence and audit logs.
- AI uses typed authorized tools; no direct financial mutation or autonomous high-risk approval.
- Separate identity, claim, evidence and financial checks.
- Provider-verified events + reconciliation determine payment truth.
- Append-only ledger; no internal wallet or unapproved custody.
- Human handoff for sensitive/uncertain cases.
- Test, document, commit at milestones; report actual SHA/push status.
