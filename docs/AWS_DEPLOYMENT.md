# AWS Deployment Baseline

Candidate services: IAM, VPC, RDS PostgreSQL, private S3, ECS/Fargate or App Runner, SQS/EventBridge, Secrets Manager, CloudWatch, WAF, backups and IaC. Validate costs/need. Least privilege, encryption, budgets, alarms, backups/restores, separate environments. No costly/destructive production operations without approval.
