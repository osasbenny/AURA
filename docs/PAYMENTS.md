# Payments & Approval Gate

Written provider approval is required for exact model, countries, connected accounts, donor corridors, fees, custody, refunds, disputes, reserves and payouts. Existing Stripe/Paystack account approval is not assumed to cover AURA. Provider-verified webhooks—not redirects—confirm payments. Use idempotency, append-only ledger and reconciliation. No card data storage, internal wallet, or custody absent explicit legal/provider approval.
